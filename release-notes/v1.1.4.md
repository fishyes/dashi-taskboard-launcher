# v1.1.4

新增 Windows 可雙擊的 Codex 任務面板啟動入口。

## Features

- 安裝包新增 `start-codex-taskboard.cmd`，雙擊後會明確執行 `dashi-launcher inject`。
- 啟動成功時自動關閉命令視窗；失敗時保留視窗與診斷訊息。
- 啟動薄殼只依賴安裝目錄內的 Launcher CLI，不寫入全域 PATH。

## 文件

- 補充雙擊啟動檔的位置與行為。

## 驗證

- `pnpm test`
- `pnpm build`
- `cargo test --manifest-path src-tauri/Cargo.toml`
- `pnpm run check:release -- --tag v1.1.4`
- `pnpm tauri build --bundles nsis`
