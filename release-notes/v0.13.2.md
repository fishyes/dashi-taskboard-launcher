# v0.13.2

## Features

- **Launcher CLI**：安裝包新增 `dashi-launcher.cmd`，支援 `status`、`start`、`stop`、`restart`、`skill reinstall` 與 `--json`
- **同一程序管理器**：CLI 透過本機認證控制通道呼叫 GUI 的 `ProcessManager`，可控制 GUI 已啟動的服務，不搶滑鼠焦點；Launcher 未執行時會靜默啟動至系統匣
- **Skill 強制重裝**：`skill reinstall` 明確替換舊的 `manage-taskboard` 實體目錄或連結，Windows 無符號連結權限時仍保留實體複製 fallback

## Fixes

- **退出不再遺留舊服務**：關閉 Launcher 時先阻止主程序立即退出，等待 Taskboard 與注入器停止後再結束應用，避免升級後舊 Node 服務殘留並被新版誤用
- **Codex 內嵌面板不再卡住**：保留 opaque sandbox 隔離，由已認證的 resident injector 透過 CDP 代理該 Taskboard instance 的 JS、CSS 與 API；避免 `null` origin 直連 loopback 被 Chromium Local Network Access 擋下
- **內嵌即時更新 fallback**：opaque iframe 改用短輪詢同步議題與 AI 對話，standalone 頁面仍使用 EventSource
