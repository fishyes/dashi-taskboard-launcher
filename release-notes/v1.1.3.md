# v1.1.3

修正 Windows 直接啟動 Codex 後任務面板消失、Launcher 無法清楚辨認注入狀態的問題。

## Features

- 新增 `dashi-launcher inject`，必要時會明確關閉並以 CDP 模式重新啟動 Codex，再注入任務面板。
- `dashi-launcher status` 新增 Codex 整合狀態，可區分尚未執行、CDP 已就緒，以及正在執行但未注入。
- 系統匣新增「使用任務面板啟動／重新啟動 Codex」入口。
- 保留非破壞性的 `start`：若 Codex 已在未開啟 CDP 的情況下執行，只回報原因，不會自行關閉 Codex。

## 文件

- 補充 Windows 正確啟動方式與 `inject` 復原流程。
