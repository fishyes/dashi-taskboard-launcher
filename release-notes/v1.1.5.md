# v1.1.5

修正新版 Windows Codex 將 CDP 綁定在 IPv6 loopback 時，任務面板無法注入的問題。

## Fixes

- Launcher 的 CDP 探測同時支援 `127.0.0.1` 與 `::1`。
- Launcher 會把實際可達的 loopback 位址傳給注入器。
- 注入器接受 IPv4、IPv6 與 `localhost` 的本機 CDP HTTP／WebSocket 端點，仍拒絕非 loopback 主機。
- 保留 v1.1.4 的雙擊啟動入口，不需要修改使用方式。
