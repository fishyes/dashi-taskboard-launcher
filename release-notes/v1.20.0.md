# v1.20.0

## Features

- **Vendored taskboard updated to upstream v1.1.22-beta.4**: merge the 8
  upstream commits since the previous v1.1.22-beta.2-era merge into
  `vendor/dashi-taskboard` while preserving the launcher runtime endpoint
  discovery (`~/.codex-pro-max/launcher-runtime.json`) and the injector
  reliability fixes. Highlights:
  - **Board and AI composer simplification**: `styles.css` sheds ~2.6k lines,
    board timer rendering is reduced, and shared task rules are consolidated.
    Inline-attachment handling moves into dedicated modules
    (`inlineAttachments.ts`, `menuEvents.ts`), replacing the
    `PendingAttachments` / `IssueMentionMenu` components and the long-flaky
    `InlineMediaComposer.test.tsx` jsdom suite (removed upstream).
  - **Server slimming**: `server/app.mjs` and `server/database.mjs` shed
    ~530 lines; `server/composer-reference.mjs` is folded away.
  - CI speedups (scoped native checks, Rust dependency caches) — upstream
    infra only, no packaged behavior change.

  component suite (`MarkdownDocument.test.tsx`) — 9 passed / 0 failed.

  the launcher endpoint discovery and injector fixes carried over untouched.
- `node scripts/check-release.mjs --tag v1.20.0` passes.
